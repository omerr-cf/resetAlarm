# Documents — Reset Alarm

Planning, research, and strategy docs for this app, carried over from the initial
research/planning phase (also mirrored in the "calm app" Claude Project so they stay
visible across chats). Read in this order if you're catching up on the project:

1. **market-research-plan.md** — the original 4-part research plan (review mining,
   social listening, willingness-to-pay, ASO/SEO) that kicked this off.
2. **market-research-findings.md** — the actual sourced findings from that research:
   confirmed pain points, the live/accelerating nervous-system-regulation trend, and
   the discovery of NEUROFIT as a direct competitor.
3. **feasibility-and-strategy.md** — NEUROFIT teardown, market-sizing reality check,
   and the technical-stack recommendation (Expo/React Native over a web PWA).
4. **idea-selection-and-recommendation.md** — the pivot: teardown of the "Early"
   push-up alarm claim, the verified Alarmy business model, a scored comparison of
   candidate directions, and the final recommendation — a task-based alarm with a
   breathing/calming "mission" instead of pushups or math.
5. **mvp-spec-and-starter-code.md** — the v1 MVP scope, what's intentionally not
   built yet, a 4-week timeline, and success metrics.
6. **product-roadmap-and-launch.md** — the v2 changelog, mascot/design rationale,
   the App Store publishing roadmap, engagement ideas, and freemium/premium
   philosophy.
7. **smoke-test-assets.md** — ad hooks, a fake-door post script, and a Van
   Westendorp pricing survey draft, ready to use whenever we run a smoke test.

The actual app code lives at the repo root (`App.tsx`, `src/`, etc.) — see the
top-level `README.md` for how to run it.
